# Contributing

Thanks for wanting to help.

- **Wrong details on a sleeve** (region, label, title, year…): use "Suggest an edit" on the film's page at
  [videotapes.io](https://videotapes.io). It needs no account. Every suggestion is checked by hand before it goes live.
- **Your own scans:** see [videotapes.io/about](https://videotapes.io/about).
- **The data model or the API:** something unclear, missing or wrong in these docs or schemas? Open an issue. Please
  don't send pull requests that change `schema/` or `api/`: they're generated from the site (see
  [MAINTAINING.md](MAINTAINING.md)), so a fix goes in there and comes back here.
- **A takedown request:** see the [legal page](https://videotapes.io/legal#takedown).

Be kind, please rewind.
